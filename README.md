# tianquiztli

A Claude Code marketplace

https://nahuatl.wired-humanities.org/content/tianquiztli

## Plugins

- **plinth** -- project setup and development tools ([pborenstein/plinth](https://github.com/pborenstein/plinth))
- **handoff** -- session pickup/wrapup and project tracking ([pborenstein/handoff](https://github.com/pborenstein/handoff))

## Install

```
/plugin marketplace add pborenstein/tianquiztli
/plugin install plinth@tianquiztli
/plugin install handoff@tianquiztli
```
